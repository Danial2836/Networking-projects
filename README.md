Designed and simulated a multi-department campus network using Cisco Packet Tracer. Implemented VLANs to segregate traffic between HR, Sales, and Engineering departments, ensuring reduced broadcast domains and improved security.
Configured Inter-VLAN routing (Router-on-a-Stick), implemented DHCP servers for dynamic IP allocation, and established OSPF for efficient routing between three distinct branch offices.
 Achieved 100 percent connectivity and successfully simulated end-to-end packet transmission with optimized latency.
